# 素书 · 六天共读

> 一天一章，六天通读《素书》。一个零依赖、单文件、可直接打开的共读阅读器。

## 项目简介

《素书》相传为秦末隐士黄石公所著，共六章、一百三十二句、一千三百六十字。传说黄石公于下邳圯桥授书于张良，张良由此辅佐刘邦建立汉朝，封留侯。全书以道、德、仁、义、礼五者一体为纲，从原始、正道、求人之志、本德宗道、遵义、安礼六章层层展开，是一部以道家思想论处世、修身、治国之道的谋略绝学。

本书按六章分章编录，设计为一「**一天一章，六天通读**」的社群共读工具：设置开始日期后，「今日共读」会自动定位当天章节；每章均可一键「分享本章」生成直达该章的链接，书友点开即跳到该章。

- **底本**：依据维基文库简体版及 ctext.org 交叉校对
- **文本**：六章，约 1360 字（不含标点）
- **形态**：纯静态单文件 `index.html`，数据全部内联，**无需构建、无后端**

## 功能特性

### 阅读
- 目录导航 + 进度条，目录带日程日期，可一键「跳到今日章」
- URL `#ch-N` 直达定位，便于在微信群分享某一章
- 双阅读模式：分页（一章一页，支持键盘 / 翻页）/ 连续长页，自由切换
- 手机优先、浅色仿书版式；PC 端左侧固定目录栏（窄屏折叠为抽屉）

### 每章内容
- **译文**：逐句「原文 ↔ 今译」对照
- **注释**：疑难字注音（ruby 标音）、通假 / 异读虚线提示（点按看说明）
- **串讲**：每章主题疏通 + 关键句解读
- **解读**：生活启发——五者一体在具体处境中的实践
- **导读**：每章导读
- **省察**：章末自省提问 +「我的践行笔记」（本机保存）

### 研读专区
结构脉络 · 核心概念词典 · 名句摘录 · 素书与当代焦虑 · 义理脊柱 · 参考书目 · 人物小传 · 章间呼应表

### 今日安心签
封面独立卡片，每天一句与当日章节呼应的安心之语，可「分享这句」。

### 工具箱
阅读设置（注音 / 连续阅读）· 共读设置（开始日期）· 我的践行笔记 · 今日安心签 · 分享。

## 使用方式

### 本地预览
直接用浏览器打开 `index.html` 即可（无需服务器）。

### 部署到 Vercel
本仓库即 Vercel 站点源。在 Vercel 导入 `AIYAZONE/sushu` 并连接 `main` 分支，推送即自动重新部署。

## 技术说明

- **单文件零依赖**：HTML / CSS / JS 与全部经文、译文、注解数据内联于 `index.html`，不引用任何外部资源（favicon 亦内联为 data URI），可离线打开。
- **分享链接**：每章「分享本章」生成 `当前域名/#ch-N` 直达链接；站点部署在任意域名下均能正确定位。
- **笔记本地保存**：践行笔记仅保存在当前浏览器（localStorage），**不会上传云端**。
- **零登录零后端**：本阅读器不含账号登录与云端同步，所有数据均在本地。
